# Swastic Footwear — Handcrafted Traditional Chappals E-Commerce Website

A modern, responsive React + Vite e-commerce website built for **Swastic Footwear** (“Tradition in Every Step”).

## Features
- **Warm Heritage Design**: Dark brown, cream, beige, and golden accent color palette with custom **SWASTIC FOOTWEAR** emblem and typography.
- **Hero Showcase**: Prominent dual-display of the **Traditional Brown Leather Chappal** and **White Handmade Traditional Chappal**, with **Shop Now** and **Explore Collection** actions.
- **Product Collection**:
  - *Traditional Brown Leather Chappal*
  - *White Handmade Traditional Chappal*
  - *Premium Braided Leather Chappal*
  - *Classic Handmade Kolhapuri Chappal*
  - Plus festive variations, all with Indian Rupee (₹) sample pricing, sizes (`6, 7, 8, 9, 10`), color finish swatches, star ratings, **View Details** modal, and **Add to Cart**.
- **Interactive Shopping Cart & Checkout**:
  - Search bar, category tabs, and price/rating sorting
  - Slide-over shopping cart with item quantity controls, subtotal/total calculation, and attractive empty-cart state
  - Checkout form (Customer Name, Mobile Number, Delivery Address, Order Summary) clearly marked as Demo Checkout
  - Direct **WhatsApp Order** integration that formats your selected items, sizes, and delivery address into a ready-to-send WhatsApp message.
- **Custom Product Photo Manager**:
  - Click **Custom Product Photos** in the top bar to upload your own chappal photos directly in the browser, or replace the image files inside `public/images/`.

## Running Locally in VS Code

1. Open the project folder `c:\swstic` in VS Code.
2. Open the integrated terminal and install dependencies (already installed):
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in the terminal (typically `http://localhost:5173`).
